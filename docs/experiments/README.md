# 실험 로드맵 (단계별 한눈에 보기)

`연구계획서.md`는 상세 원본. **이 폴더는 그걸 단계별로 쉽게 보도록 나눈 요약본**이다.
각 문서는 `방법론 → 결과` 순서이고, 아직 안 한 것은 결과를 공백으로 둔다.

---

## 논문의 척추 — 3단계

이 연구는 **하나의 질문을 세 층으로 파고든다.** 이게 논문의 핵심 구조다.

```
1단계  현상이 실제로 있는가?           → 행동 실험 (01 행동실험; 추가 실험은 보류)
          ↓
2단계  그게 attention에서 보이는가?     → attention 관측 (지침 참조 비율)
          ↓
3단계  attention이 실제 원인에 기여하는가? → attention 개입 (P1a·P2)   ← 논문의 진짜 새로움
```

- **1단계 = 논문의 본체이자 발판.** "선행 위반 코드가 규칙 준수를 낮춘다"를 통제 실험으로 확립.
- **2단계 = 상관.** 그 행동이 일어날 때 모델이 실제로 위반 코드 구간을 더 참조하는지 **관측**(인과 주장 안 함).
- **3단계 = 인과.** attention/KV를 직접 **개입**해 준수 결정이 바뀌는지 봄. **여기가 기여의 핵심.**
- 어느 단계에서 멈춰도 논문이 성립(보험). 단 **거저 확립되던 현상(1단계)에 그치지 않고 2·3단계로 가는 것이 이 연구의 목적.**

> ⚠️ **헷갈리지 말 것:** "행동 실험(01·추가)"과 "1/2/3단계"는 **다른 축**이다.
> **01 행동실험과 추가 실험은 전부 1단계(행동) 안**에 있고, 2·3단계는 attention이다.

### 현재 초점 (main line)

핵심 주장 하나 — **"코드 에이전트가 앞서 생성된 코드를 참조하다가, 지시와 반대되는
예시가 쌓이면 지시를 따르지 않는다"** — 를 아래 한 줄로 관통시키는 데 집중한다.

```
01 행동실험 (확증)  →  2단계 (attention 관측)  →  3단계 (개입, 인과)
```

**추가 실험(옛 실험 2·3)은 보류.** 방법론은 [`archive_보류·실패.md`](archive_보류·실패.md)에 보존(추후 재개), 지금은 위 main line만 진행한다.

## 주 가설 (사전 등록 — 이 셋만, 계획서 4장 원문)

- **H1a** — context 내 위반 코드가 후속 함수의 규칙 준수율을 낮춘다 (1단계 · 01 행동실험) — **1차 확증**
- **H2a** — Violation-style < Compliant-style 준수율(순수 스타일 효과) (추가 실험 A) — **미실행(보관)**
- **H3** — 규칙 등급 비대칭: 금지형 규칙 효과 > 수행형 규칙 (추가 실험 B, H2 하네스) — **미실행(보관)**

> ⚠️ **라벨 주의.** 3단계 attention 개입이 검정한 것은 계획서상 **H7(P1a)·H8(P2)** 이며 **주 가설이 아니다**
> (기제 수준 개입 가설, 선호 수준에서 확증). 과거 문서가 이 개입을 "주 가설 H3"로 표기했던 것은
> 계획서 H3(규칙 등급 비대칭)와의 혼동이자 규칙 6(사후 주 가설 금지) 위반이라 정정했다
> (경위: [`../observations.md`](../observations.md) 메타 관찰 2026-08-05).

나머지는 전부 탐색적 보고. 사후에 주 가설을 추가하지 않는다.

## 모델 (계획서 5.1)

- **프런티어**(Claude Sonnet·GPT, API) — 행동 실험(1단계)의 외적 타당도. 가중치 불필요.
- **오픈**(Qwen2.5-Coder-7B 주, 14B·32B 규모 확인) — 행동 + **attention 관측·개입(2·3단계는 여기서만 가능)**.
