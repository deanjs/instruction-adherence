# 3단계 — attention 개입 (P1a·P2)

주 가설 **H3**: attention/KV 개입이 준수 선호 점수를 **인과적으로** 바꾼다.
관련 계획서 절: 3.5(점수화), 3.6(개입). **논문의 진짜 새로움이 여기 있다.**

> 2단계는 "attention을 많이 준다"까지만 본다. 3단계는 그 attention/KV를 **직접 치환·조정**해
> 준수 결정이 바뀌는지 봄으로써 **인과 기여**를 확립한다. 오픈 모델(Qwen)에서만 가능.

---

## 방법론

### 준수 선호 점수 (3.5)

이진 판정은 개입 실험에 너무 거칠다. 연속 점수를 쓴다.

```
준수 선호 점수 = (1/|Y_c|)·log P(Y_c | X) − (1/|Y_v|)·log P(Y_v | X)
  Y_c 준수 표기 후보(getUserOrders), Y_v 위반 표기 후보(get_user_orders), teacher forcing
```

- **후보는 조건 공통의 사전 고정 문자열.** 모델이 실제 생성한 이름에서 뽑으면 조건 간 준수 선호 점수 차이가
  선호 차이인지 문자열 차이인지 구분 불가 → **모든 조건에서 동일한 두 문자열을 채점**한다.
- 실제 생성 이름은 별도 기록해 행동 판정에만 사용(두 측정 분리).
- 보조: 정확히 한 토큰에서 갈리는 사례의 logit 차이. 길이 정규화 편향 때문에 비정규화 로그확률차도 함께 보고.

### 개입 전용 pair (3.6) — 토큰 정확 일치

행동 실험의 ±3 토큰 허용을 **여기 적용 금지.** 1토큰만 달라도 위치 인덱스·RoPE가 어긋나 K/V 치환이 정의 안 됨.
→ 두 표기의 **총 토큰 수 동일 + 결정 지점 인덱스 동일** pair만 사용(Step 0에서 316쌍 확보).

### 왜 지침 구간을 교체하는 건 무의미한가 (3.6)

causal mask 때문에 지침 K/V는 두 조건에서 비트 단위로 동일 → 교체해도 아무 변화 없음.
조건 간 실제로 다른 건 **① 선행 코드 구간 K/V, ② 결정 지점 query(→ 지침에 대한 α도 달라짐)** 둘뿐.
지침 `v_i`는 같으므로 `c_I` 차이는 **오직 α 때문** — 이게 개입 설계를 결정한다.

### 네 가지 개입 — GQA 단위 주의

Qwen은 GQA(query head 28, KV head 4, 7:1 공유).

| 개입 | 조작 대상 | 단위 | 층당 수 |
|---|---|---|---|
| **P1a (주)** | query 고정, 코드 구간 K/V를 준수 실행 값으로 치환 후 α 재계산 | **KV group** | **4** |
| **P2 (보조)** | 위반 조건 내부에서 지침 구간 α에 배율 λ∈{0.5,1,2,4,8} (PASTA 계열, 양-반응) | query head | 28 |
| P1b (탐색) | 코드 구간 기여분 `c_C` 이식 | query head | 28 |
| P3 (탐색) | 지침 구간 기여분 `c_I` 교차 교체 | query head | 28 |

- **P1a를 query head 단위로 짜면 안 됨** — K/V는 group 내 7개 head가 공유하므로, 실제론 7개를 건드리면서 1개로 보고하게 됨. **P1a는 KV group 4개** 단위로 순회.
- 개입은 후보 함수명의 **모든 teacher-forcing step**에 동일 적용 후 sequence 수준 준수 선호 점수 계산(보조: 첫 토큰만).
- 질량 보존 변형을 주 결과(배분 변화만 분리), 비보존은 총량 변화 공변량으로 보고.

### 개입 효과 판정 (3.6)

- **주 지표 준수 선호 점수 변화량** = `개입본 준수 선호 점수 − 손상본 준수 선호 점수`. **준수 선호 점수로 표본을 선별하지 않는다**(순환 논증·평균 회귀 오독 방지). 선별 기준은 토큰 수 일치·함수명 속성·명세 슬롯 등 준수 선호 점수 무관 사전 기준만.
- **표본 분할:** A(50쌍)=기저 준수 선호 점수 변화량 추정 전용, B(50쌍)=개입 실행. Recovery Ratio = B의 준수 선호 점수 변화량 ÷ A의 기저 준수 선호 점수 변화량(분자·분모 상관 회피).
- **음성 대조**(효과가 **없어야** 함): no-op patch, 무관 구간 patch, R 구간 patch, 무작위 단위 patch.
  → 무작위 개입 준수 선호 점수 변화량 분포를 **귀무분포**로, P1a가 상위 꼬리인지 검정(**주 판정 기준**).
- 순회: P1a = 전 층 × KV group 4, P2 = 전 층 × query head 28. 음성 대조도 동일 범위.

### 절대 규칙 (완화 금지)

1. 준수 선호 점수 값으로 표본 선별 금지. 2. 후보는 전 조건 동일 문자열. 3. 개입 pair 토큰 수 정확 일치.
4. P1a는 KV group(4), P2/P1b/P3는 query head(28). 5. 주 가설은 H3.
