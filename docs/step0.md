# Step 0 — 개입 실험용 함수명 pair 토큰 수 일치 수율 측정

**상태:** 완료 · **모델:** Qwen/Qwen2.5-Coder-7B-Instruct (tokenizer만) · **GPU:** 불필요

---

## 왜 이걸 먼저 했나

계획서 7장 일정은 1주차가 "도구 구현"이지만, 그 앞에 **하루 안에 끝나면서
프로젝트를 죽일 수 있는 것**을 먼저 확인했다. 도구를 다 만든 뒤에
설계가 성립하지 않는다는 걸 알게 되면 손실이 크다.

3단계 개입 실험(P1a: K/V 치환)은 준수 조건과 위반 조건의
**토큰 위치가 정확히 일치해야만** 성립한다. 1토큰만 어긋나도
결정 지점 인덱스가 밀리고 RoPE 위치 표현이 달라져 K/V 교체가 정의되지 않는다.

그런데 `getUserData` 와 `get_user_data` 가 같은 토큰 수로 쪼개진다는 보장이 없다.
이 수율이 너무 낮으면 개입 실험 설계 자체를 바꿔야 한다.
계획서 "위험 요소" 표의 *토큰 수 일치 pair 수율 부족* 항목에 해당한다.

확인 비용은 tokenizer 다운로드 + 스크립트 실행으로 몇 분이다. 가장 싸고 가장 치명적이다.

## 무엇을 쟀나

동사 22개 × 명사 조합 18개 = **후보 396쌍**을 기계적으로 생성하고,
각 쌍을 네 가지 context에 넣어 tokenize한 뒤 다음을 판정했다.

1. 두 시퀀스의 총 토큰 수가 같은가
2. 갈리기 전까지의 토큰이 완전히 동일한가 (결정 지점 인덱스가 같은가)

| context | 형태 |
|---|---|
| `bare` | 이름만 |
| `def` | `\ndef ` |
| `def_in_class` | 클래스 선언 안의 메서드 |
| `with_code` | 앞에 함수가 하나 있는 상태 |

## 결과

| context | 일치 | 일치율 | 단일 토큰 분기 |
|---|---|---|---|
| bare | 325/396 | 82.1% | 129 |
| def | 316/396 | **79.8%** | 125 |
| def_in_class | 316/396 | **79.8%** | 125 |
| with_code | 316/396 | **79.8%** | 125 |

**판정: 통과.** 사전 기준 40%를 두 배 가까이 넘겼다. 개입 실험 설계를 그대로 유지한다.

### 해석

**세 context가 정확히 같은 숫자인 것은 버그가 아니다.**
`def`, `def_in_class`, `with_code` 모두 프롬프트가 `"def "` 로 끝난다.
BPE는 국소적으로만 병합하므로 앞에 무엇이 오든 이름이 쪼개지는 방식은 변하지 않는다.
`bare` 만 다른 것은 앞에 공백이 없기 때문이다.

이는 오히려 유용한 결과다. **매칭 목록이 prefix 구성과 무관하게 안정적**이므로,
prefix 세트를 바꿀 때마다 토큰 정렬을 다시 검증할 필요가 없다.

**필요 수량을 충족한다.** CPS 후보 100쌍(분할 A/B 각 50)을 쓰고도 216쌍이 남아,
prefix 함수 4개 세트를 54개 구성할 수 있다. 이름 풀 확장이 필요 없다.

**보조 지표 적용 범위:** 단일 토큰 분기는 125/316 = **39.6%**.
계획서 3.5의 보조 지표(단일 토큰 logit 차이)는 매칭 표본의 약 40%에서만 계산 가능하다.
계획서에 "해당 조건을 만족하는 비율도 함께 보고한다"고 명시돼 있으므로 그대로 이행한다.

## 중간에 고친 것 (v1 → v2)

v1은 `def` 계열에서 396/396 전부를 "prefix 경계 병합"으로 튕겨내 일치율 0%를 냈다.
스크립트 버그였다.

prefix `"\ndef "` 는 끝에 공백이 있는데, Qwen BPE는 공백을 뒤 단어에 붙여
` get` 같은 토큰을 만든다. 그래서 `"\ndef "` 를 **단독으로** tokenize한 결과가
`"\ndef getUserData"` 의 앞부분과 일치하지 않는다.

실제 실험에서는 prefix를 따로 tokenize할 일이 없다. 전체 문자열을 한 번에 넣는다.
v2는 prefix 보존을 요구하지 않고 **두 전체 시퀀스를 직접 비교**하도록 바꿨다.
